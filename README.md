# stuntcopter.donwilson.net

The website for the StuntCopter game, served by GitHub Pages from the `master` branch: the home page, the [privacy policy](https://stuntcopter.donwilson.net/privacy) and the [support page](https://stuntcopter.donwilson.net/support). The store listings link to the privacy policy, so keep it in step with what the game collects.

It's plain HTML and CSS with no build step. Pages are linked without the `.html` extension, which GitHub Pages resolves.

This repository also holds the public [issue list](https://github.com/dontangg/stuntcopter.donwilson.net/issues) for bugs and ideas.
